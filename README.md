# Spam Message Detector

A beginner-friendly Machine Learning project that detects whether a message is spam or normal using TF-IDF vectorization and Naive Bayes classification with a Tkinter graphical interface.

## Features

* Spam / Ham classification
* Text preprocessing
* TF-IDF vectorization
* Naive Bayes model
* GUI using Tkinter
* Probability prediction
* Model saving using Pickle

## Technologies Used

* Python
* Scikit-learn
* Pandas
* Tkinter
* Pickle

## Installation

```bash
pip install -r requirements.txt
python spam_detector.py
```

## Project Workflow

1. User enters message
2. Text preprocessing
3. TF-IDF converts text to vectors
4. Naive Bayes predicts class
5. GUI displays result

## Example Predictions

Spam:

`Congratulations! You won 1 million rupees`

Normal:

`Hey, are we meeting tomorrow?`
